# Bibliotecas, conteúdos e créditos

- **qrcode-generator 2.0.4**, Kazuhiko Arase, MIT. Código incorporado em `vendor/qrcode.js`; o cabeçalho original contém o aviso de licença. Fonte: https://github.com/kazuhikoarase/qrcode-generator . Não utiliza servidor remoto para gerar QR.
- **Firebase JavaScript SDK 12.18.0**, Google, Apache-2.0. Carregado do CDN oficial somente quando configurado. https://github.com/firebase/firebase-js-sdk
- **JSZip 3.10.1**, licenças MIT/GPLv3; usado sob MIT para empacotar releases. https://github.com/Stuk/jszip
- **JSDOM**, MIT, e ferramentas de teste Firebase: dependências de desenvolvimento, listadas com versões fixas em `package.json` e resoluções em `pnpm-lock.yaml`.
- Dependências transitivas conservam as respectivas licenças distribuídas por seus autores. Não incluímos `node_modules` no ZIP.
- Músicas, letras e artistas de demonstração são fictícios, criados para este projeto; não foram copiados de um catálogo de terceiros.
- Avatar Vale: imagem original gerada para o Stage Music, representando um personagem fictício. Arquivo local em `assets/vale.webp`.
- Marca/ícones de interface: elementos vetoriais do projeto. Não há fontes externas, imagens de terceiros ou scraping de letras.

O PDF fornecido pelo usuário foi usado como referência de requisitos e não foi redistribuído dentro do pacote.
